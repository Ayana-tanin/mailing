"""
Рассылка через WhatsApp Web (Playwright), версия 2.

Файлы рядом со скриптом:
    numbers.csv - БЕЗ заголовка: название компании, номера через ;
        Hostel 312,+996500000001
        "Compass, хостел",+996700000002; +996770000003
    message.txt - 2-3 варианта текста, разделённых строкой ---
        Здравствуйте, {name}! Вариант 1...
        ---
        Добрый день, {name}! Вариант 2...
        ---
        {name}, приветствуем! Вариант 3...
    {name} заменяется на название компании.

Логика:
    - у компании перебираются номера по порядку;
    - как только на каком-то номере есть WhatsApp и сообщение ушло - переходим к следующей компании;
    - если WhatsApp нет - проверяется следующий номер;
    - варианты текста идут по кругу (1, 2, 3, 1, 2, 3...), счётчик сохраняется между запусками.
"""
